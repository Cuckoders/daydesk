# DayDesk Mobile

Мобильный клиент DayDesk для iPhone, iPad и Android на Expo + React Native.

## Уже работает

- обзор дня, задачи, календарь, ритм дня и экран единой почты;
- создание, редактирование, завершение и удаление задач и локальных событий;
- полноценное управление «Ритмом дня»: собственные ритуалы, дни недели, время, тип, опережение уведомления и быстрое включение;
- приоритеты, категории, сроки и повтор по дням/будням/неделям;
- локальные системные напоминания о задачах, событиях и ритуалах по выбранным дням недели;
- offline-first хранение в AsyncStorage и очередь изменений для синхронизации;
- защищённая push/pull-синхронизация задач, событий и ритуалов с `server/`, автоматический обмен при возвращении сети;
- единые входящие Gmail, Outlook и IMAP-аккаунтов, поиск, фильтр по ящикам, просмотр обычного текста и управление подключениями;
- новое письмо и ответ из reader, выбор до 10 исходящих вложений, отдельное подтверждение перед отправкой;
- светлая и тёмная темы, 48px зоны касания, VoiceOver/TalkBack labels;
- deep link из уведомления сразу в нужную задачу или ритуал.

Пароли IMAP, OAuth-токены, черновики, вложения и содержимое почты в AsyncStorage не сохраняются. OAuth открывается в системном браузере, а токены получает и шифрует только sync-сервер. Пароль приложения сразу передаётся авторизованному backend-коннектору, шифруется серверным ключом и после завершения формы очищается из состояния экрана. Исходящие файлы живут на сервере только в оперативной памяти до 15 минут и удаляются после отправки или закрытия composer. Входящие загружаются заново после перезапуска приложения; HTML, скрипты и внешние изображения писем не отображаются.

## Запуск

```bash
cd mobile
npm install
npm run ios
# или
npm run android
```

Для локальных уведомлений на современных версиях Expo используйте development build; Expo Go поддерживает модуль уведомлений с ограничениями.

## Синхронизация

Сначала запустите [DayDesk Sync Server](../server/README.md), затем нажмите значок облака на экране «Сегодня». Укажите адрес сервера, регистрационный setup-код и название телефона. Выданный device-token сохраняется только в SecureStore.

Для iOS Simulator подойдёт `http://127.0.0.1:4310`. Физическому телефону нужен доступный адрес локальной сети; перед доступом из интернета обязательно используйте HTTPS.

Перед подключением почты задайте серверу `DAYDESK_MAIL_KEY`, затем откройте вкладку «Почта» → настройки. Gmail и Outlook подключаются через OAuth 2.0; серверные client ID, secret, HTTPS origin и callback описаны в [server/README.md](../server/README.md). Для Yandex, Mail.ru, iCloud и других IMAP-ящиков используйте отдельный пароль приложения.

Проверка без CI:

```bash
npx tsc --noEmit
npx expo export --platform web
```
