# DayDesk Mobile

Мобильный клиент DayDesk для iPhone, iPad и Android на Expo + React Native.

## Уже работает

- обзор дня, задачи, календарь, ритм дня и экран единой почты;
- создание, редактирование, завершение и удаление задач и локальных событий;
- полноценное управление «Ритмом дня»: собственные ритуалы, дни недели, время, тип, опережение уведомления и быстрое включение;
- приоритеты, категории, сроки и повтор по дням/будням/неделям;
- локальные системные напоминания о задачах, событиях и ритуалах по выбранным дням недели;
- offline-first хранение в AsyncStorage и очередь изменений для синхронизации;
- защищённая push/pull-синхронизация задач, событий и ритуалов с `server/`, автоматический обмен при возвращении сети;
- единые папки «Входящие» и «Отправленные» Gmail, Outlook и IMAP-аккаунтов, поиск, фильтр по ящикам и просмотр обычного текста;
- входящие вложения до 2 МБ по запросу через системное меню iOS/Android с немедленной очисткой временного cache-файла;
- импорт одиночного `.ics`-приглашения в редактор встречи с проверкой названия, времени, места и 15-минутным напоминанием для встреч с указанным временем;
- создание задачи из темы любого открытого письма с редактируемым сроком, приоритетом и локальным напоминанием;
- приватная фоновая проверка новой почты с одним сгруппированным уведомлением без темы и отправителя на экране блокировки;
- новое письмо и ответ из reader, выбор до 10 исходящих вложений, отдельное подтверждение перед отправкой;
- светлая и тёмная темы, 48px зоны касания, VoiceOver/TalkBack labels;
- deep link из уведомления сразу в нужную задачу или ритуал.

Пароли IMAP, OAuth-токены, почтовые черновики, вложения и содержимое почты в AsyncStorage не сохраняются. OAuth открывается в системном браузере, а токены получает и шифрует только sync-сервер. Пароль приложения сразу передаётся авторизованному backend-коннектору, шифруется серверным ключом и после завершения формы очищается из состояния экрана. Исходящие файлы живут на сервере только в оперативной памяти до 15 минут и удаляются после отправки или закрытия composer. Входящее вложение загружается только после нажатия, временно записывается в cache и удаляется после закрытия системного меню. Черновики встречи из `.ics` и задачи из письма существуют только в памяти до открытия редактора; неоткрытые черновики очищаются не позднее чем через 10 минут. После явного сохранения отредактированная тема письма становится обычным названием задачи и синхронизируется как пользовательская задача. HTML, скрипты и внешние изображения писем не отображаются.

Фоновую почту пользователь включает сам на экране синхронизации. В SecureStore сохраняются только усечённые SHA-256-отпечатки идентификаторов последних писем — без отправителей, тем и текста. Android WorkManager и iOS BGTaskScheduler запускают проверку не чаще минимального интервала 15 минут, но точное время определяет система. Функция требует development/production build; Expo Go и iOS Simulator не подходят для полноценной проверки фонового выполнения.

Android-сборка явно блокирует legacy-разрешения `READ_EXTERNAL_STORAGE` и `WRITE_EXTERNAL_STORAGE`: выбор исходящих файлов и сохранение входящих выполняются через системные интерфейсы без широкого доступа к общему хранилищу.

## Запуск

```bash
cd mobile
npm install
npm run ios
# или
npm run android
```

Для локальных уведомлений на современных версиях Expo используйте development build; Expo Go поддерживает модуль уведомлений с ограничениями.

## Синхронизация

Сначала запустите [DayDesk Sync Server](../server/README.md), затем нажмите значок облака на экране «Сегодня». Укажите адрес сервера, регистрационный setup-код и название телефона. Выданный device-token сохраняется только в SecureStore.

Для iOS Simulator подойдёт `http://127.0.0.1:4310`. Физическому телефону нужен доступный адрес локальной сети; перед доступом из интернета обязательно используйте HTTPS.

Перед подключением почты задайте серверу `DAYDESK_MAIL_KEY`, затем откройте вкладку «Почта» → настройки. Gmail и Outlook подключаются через OAuth 2.0; серверные client ID, secret, HTTPS origin и callback описаны в [server/README.md](../server/README.md). Для Yandex, Mail.ru, iCloud и других IMAP-ящиков используйте отдельный пароль приложения.

Проверка без CI:

```bash
npx tsc --noEmit
npx expo export --platform web
```
